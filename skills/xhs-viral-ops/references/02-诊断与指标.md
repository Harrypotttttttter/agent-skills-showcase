# 诊断与指标：数据不好时，先找到掉在哪一环

这份文档解决"笔记发出去没量，但不知道是封面、内容还是账号出了问题"的问题。核心方法是把曝光量分层、把指标对照达标线，定位到具体那一环，再给对应动作——而不是笼统说"内容不够好"。

> 口径声明：本文所有达标线与占比均为经验值，非官方数据，看趋势用；用于同赛道、同量级账号的横向对比和自己的纵向对比，不是及格线。

## 一、先懂机制：半搜索半推荐

小红书流量=推荐流量+搜索流量双引擎。推荐是平台主动把笔记推给可能感兴趣的人，搜索是用户主动找答案时刷到你。两条路逻辑不同，诊断时先分清你的量主要来自哪条。

| 流量来源 | 占比量级（经验值） | 由什么决定 | 用户意图 |
|---|---|---|---|
| 发现页推荐 | 50%-70% | 点击率、互动率、收藏率 | 被动刷到 |
| 搜索 | 20%-40% | 关键词布局、内容相关度 | 主动找答案 |
| 关注页 | 5%-15% | 粉丝基数和粘性 | 已关注你的人 |
| 个人主页 | 3%-10% | 主页装修、置顶内容 | 被点进主页 |

判断方法：后台看"观看来源"或直接看数据构成。搜索占比高的笔记，长尾流量能持续几个月，值得长期维护；推荐占比高的笔记爆发快但也衰减快。

## 二、流量池阶梯与通过条件

笔记发布后不是一次推给所有人，而是一层层过关。每一层达标才进下一层，卡在哪层就查哪个指标。

| 层级 | 曝光量级（经验值） | 通过条件 | 卡住时重点查 |
|---|---|---|---|
| 冷启动池 | <500 | 封面标题点击率达标 | 首图版式、标题公式、账号是否正常 |
| 初级流量池 | 500-3000 | 互动率达标 | 正文价值、结尾互动设计 |
| 中级流量池 | 3000-1w | 收藏率、完读率达标 | 可存性、正文前3行 |
| 大流量池 | 1w以上 | 涨粉率、人设沉淀 | 主页三件套、关注理由 |

## 三、权重构成：哪个指标更重要

不是所有互动等价。平台更看重"用户愿不愿意把这篇存下来以后再看"，因为这代表内容有长期价值。

| 指标 | 相对权重 | 为什么 |
|---|---|---|
| 收藏率 | 高 | 代表实用价值和长期留存意愿 |
| 互动率（含评论、分享） | 中高 | 评论和分享代表真实讨论与传播 |
| 完读率 | 中 | 代表内容质量和开头吸引力 |
| 点击率 | 中（决定入场券） | 决定能不能进池，但不决定走多远 |
| 点赞率 | 低 | 成本最低的动作，权重最低 |

一句话记住：**收藏>评论分享>完读>点击>点赞**。点赞多但收藏少，通常说明内容好看不好用，不算好笔记。

## 四、限流三型：判定与处理

限流分三种，表现不同、处理也不同。先判定类型再对症下药，别一上来就改内容、频繁改主页或批量删笔记——那会加重账号级问题。

| 类型 | 判定信号 | 常见原因 | 处理动作 |
|---|---|---|---|
| 单篇限流 | 只有这一篇曝光<500，其他正常 | 该篇含违禁词、搬运、硬广 | 跑合规机检，改标题正文；改后仍不行就删除重发（换封面和首句） |
| 账号限流 | 连续多篇曝光骤降、搜索不到自己 | 账号违规累积、异常行为 | 停发3-7天，查站内信违规通知，清理违规笔记，恢复期只发优质原创 |
| 关键词限流 | 特定词相关笔记都不给量 | 词本身敏感或竞争违规 | 换同义关键词、从标题和话题中移除该词 |

## 五、收录三要素与发布黄金2小时

**收录三要素**——想被搜到，这三处必须含核心关键词：

1. **标题**：核心搜索词尽量靠前，用户搜什么就写什么。
2. **正文前100字**：自然嵌入核心词和1-2个长尾词，别堆砌。
3. **话题**：带1-3个与内容强相关的话题，其中含核心词。

**发布后2小时黄金窗口**（经验值，非官方数据，看趋势用）：笔记发布后头2小时平台会给一小波初始流量测试。这段时间点击率和互动率的表现，很大程度决定能不能进下一层池。动作清单：

- 发布后2小时内尽量在线，及时回复前几条评论（拉高互动率和评论数）。
- 自己先补一条评论，抛开放式问题引导讨论。
- 转发到自己的其他社交圈，拉真实初始点击，别刷量。
- 24小时后看一次数据趋势，2小时后基本定型，不用频繁刷后台。

## 六、六个核心指标达标线

| 指标 | 计算口径 | 达标线（经验值） | 不达标说明 |
|---|---|---|---|
| 点击率 | 阅读÷曝光 | 8%-15% | 封面标题没吸引力 |
| 互动率 | (赞+藏+评+分享)÷阅读 | 5%-10% | 正文价值或互动设计不足 |
| 收藏率 | 收藏÷阅读 | >3% | 缺可存内容 |
| 涨粉率 | 新增关注÷阅读 | >1% | 人设没立住 |
| 完读率 | 滑到底÷阅读 | >30% | 前3行没给结论 |
| 评论率 | 评论÷阅读 | >0.5% | 结尾没留互动口子 |

> 再次强调：以上均为经验值，非官方数据，看趋势用。不同赛道差异很大（如教程类收藏率天然高、情绪类点赞天然高），跨赛道直接比数字没有意义。

## 七、诊断树：按曝光量定位问题

拿到数据按曝光量走对应分支，一次只查一个问题：

```
曝光量多少？
├─ <500（没出冷启动池）
│   └─ 查点击率：低于8% → 换封面版式+标题公式；查账号有无违规；别原样重发
├─ 500-3000（卡在初级池）
│   └─ 查互动率：低于5% → 拆收藏率/评论率/完读率
│        ├─ 收藏<3% → 加清单/表格/步骤
│        ├─ 评论<0.5% → 结尾加开放式提问
│        └─ 完读<30% → 重写开头，结论前置
├─ 3000-1w（卡在中级池）
│   └─ 查收藏率与完读率：决定能不能进大池，补可存性和正文结构
└─ 1w-5w（进了大池但不涨粉）
    └─ 查涨粉率：低于1% → 主页三件套补齐，正文给明确关注理由
```

一个例外提醒：如果点赞远高于收藏（如点赞是收藏的3倍以上且点赞>50），即使互动率达标，也优先把内容往"值得存的工具型笔记"方向改——点赞权重最低，收藏才是硬指标。

## 八、配套工具

数据诊断交给 `scripts/diagnose.py`，把上面的达标线和诊断树都代码化了，纯本地运行。

```bash
# 单篇诊断：填入从后台抄来的真实数据（别编造）
python3 diagnose.py --impressions 2000 --reads 120 --likes 8 \
  --collects 3 --comments 1 --fans 0 --title "通勤包分享"

# 批量诊断：CSV 列名 title,impressions,reads,likes,collects,comments,shares,fans,readthrough
python3 diagnose.py data.csv --json
```

- 参数：`--impressions` 曝光、`--reads` 阅读、`--likes` 点赞、`--collects` 收藏、`--comments` 评论、`--shares` 分享、`--fans` 新增关注、`--readthrough` 滑到底人数（可省）。
- 脚本按曝光量自动分层，逐条输出"指标→原因→动作"，`--json` 输出会自带达标线免责声明。
- 用户没给的数据不要填0糊弄，尤其 `readthrough` 没有就让它空着，脚本会提示"无法判断正文结构"，比假数据更有价值。
- 退出码0为分析完成，1为输入错误或字段缺失。诊断结果是候选结论，动作要不要采纳还要结合内容实际。
