# 合规红线：发之前先扫一遍，别让一篇毁一个号

这份文档解决"文案会不会违规、会不会被判搬运、发前到底该查什么"的问题。核心原则：合规优先于流量——命中硬性违禁词必须改到零才交付，搬运和刷量一律不做。

> 说明：下列红线量级参考公开平台规则的常见口径，用于自查，不构成法律意见；具体以平台最新规则为准。

## 一、八类红线：反面例子与合规说法

| 类别 | 反面例子（不要写） | 合规说法（改成这样） |
|---|---|---|
| 医疗功效 | "根治痘痘""三天见效""治愈敏感肌" | "我个人用着有缓解""坚持使用观察变化" |
| 站外导流 | "加微信私聊我""扫码进群""v我" | "站内评论区交流""有问题评论区说" |
| 绝对化 | "全网最好""第一""100%有效""顶级" | "我个人觉得较好""之一""大部分情况适用" |
| 诱导互动 | "点赞过万抽奖""转发抽奖""不转不是XX人" | "喜欢可以先收藏""欢迎评论区聊聊" |
| 虚假种草 | "已下单""无广亲测""无限回购" | "我把自己的使用体验说一下"（亲测/种草类词需人工确认上下文） |
| 金融承诺 | "稳赚""躺赚""暴富""无效退款" | "收益因人而异""以实际体验为准" |
| 数据造假 | 刷赞刷收藏、P图伪造订单和聊天记录 | 只用真实数据，不刷不P不伪造 |
| 其他专项 | 烟酒、未成年人不当出镜、危险动作、敏感话题 | 避开专项监管品类和内容，做普通生活分享 |

判断口径：功效类看"有没有把话说死"、导流类看"有没有把人往站外拉"、互动类看"有没有用利益或道德绑架换互动"。拿不准就往保守里改。

## 二、图片里的隐性违规

文字过关了，图里也会踩雷。发布前逐张检查：

| 风险点 | 表现 | 处理 |
|---|---|---|
| 二维码/联系方式 | 图里拍到二维码、微信号、手机号 | 裁掉或打码，绝不留 |
| 包装功效宣称 | 产品包装上有"最""根治"等字样被拍进去 | 遮挡或换角度 |
| 前后对比图 | 过度对比暗示医疗/夸大效果 | 不用刺激性对比 |
| 品牌标识 | 大量露出竞品logo、遮挡商品关键信息 | 弱化或打码 |
| 未成年人 | 儿童正脸无监护人同意、不当出镜 | 避免或打码 |
| 危险动作 | 模仿危险操作、违规交通行为 | 不拍不发 |

## 三、处罚处置流程

发现风险后按这个顺序处理，别凭感觉：

1. **立即停发**：未发布的先存草稿，别带着风险发出去。
2. **机检分类**：用合规脚本扫一遍，分出 HARD（必改）和 SOFT（人工确认）。
3. **逐条改写**：HARD 按建议替换到零命中；SOFT 结合上下文判断，能保守就保守。
4. **复检确认**：改完再扫一次，HARD 必须为0才放行。
5. **已发布被限流**：按诊断文档的限流三型处理——单篇改标题正文、账号级停发3-7天养号（经验值，非官方数据，看趋势用）、关键词级换词。

## 四、发布前10条终检清单

发之前逐条打勾，任一条没过就别发：

- [ ] 1. 无绝对化用词（最/第一/100%/顶级/绝对）
- [ ] 2. 无医疗功效宣称（根治/治愈/三天见效/美白祛斑）
- [ ] 3. 无站外导流（微信/私聊/扫码/外链）
- [ ] 4. 无诱导互动（点赞抽奖/转发抽奖/道德绑架）
- [ ] 5. 无金融收益承诺（稳赚/躺赚/暴富/退款保证）
- [ ] 6. 种草、亲测、平替类词已结合上下文确认无误导
- [ ] 7. 数据真实，无刷量、无P图伪造
- [ ] 8. 图片无二维码、无夸大对比、无未成年不当出镜
- [ ] 9. 与对标原文的整句重合为0，图片是自己拍/做的
- [ ] 10. 已跑机检，HARD 命中数为0

## 五、"内容搬运"的合规边界

这是最容易踩的灰区。一句话记住：**拆解骨架可以用，原句照搬不能用**。

| 维度 | 可以（骨架） | 不可以（表层） |
|---|---|---|
| 结构 | 用它的"分几点、什么顺序" | 整段结构+措辞一起搬 |
| 措辞 | 学句式类型 | 出现≥10字相同句 |
| 经历 | 学叙事视角 | 把别人的故事换名字当自己的 |
| 案例 | 学举例角度 | 照搬具体案例和数据 |
| 图片 | 学版式思路 | 直接搬运原图 |

改写到什么程度算原创？四个"换"必须全做：

1. **换结构**：不是照搬原顺序，重新组织信息流。
2. **换措辞**：所有句子用自己的话重写，不留相同整句。
3. **换案例**：举例、场景、数据换成自己素材。
4. **换图**：封面和配图全部自己拍或自己做。

只换其中一两项不算原创，机检会抓出整句雷同。四换全做，既合规又不容易限流。

## 六、配套工具

发布前机检交给 `scripts/compliance.py`，纯本地运行、内置词表，不调用任何付费接口。

```bash
# 检查文案文件
python3 compliance.py copy.txt

# 带对标原文查整句照抄（搬运风险）
python3 compliance.py copy.txt --reference viral.txt --json

# 管道输入一句话快速自查
echo "待发布文案" | python3 compliance.py -

# 看内置样例
python3 compliance.py --demo
```

- 输出分两类：`HARD` 命中必须替换（绝对化/功效/诱导/导流等），`SOFT` 需人工确认上下文。
- 传入 `--reference` 会检测与对标原文的整句重合（≥10字相同句判定为搬运风险）。
- **HARD 必须清零**：退出码1表示命中 HARD、禁止发布，改到退出码0才放行；退出码2为用法/文件错误。
- `verdict` 有三种：BLOCK（有HARD）、REVIEW（有SOFT或搬运嫌疑）、PASS（可发）。机检查不出图片和经历的原创性，那部分靠第四节终检清单人工把关。
