# 竞品拆解：看懂别人为什么火，把骨架变成自己的

这份文档解决"看了一堆爆款却不知道怎么学、一学就变成照抄"的问题。方法是用统一的八维框架把对标笔记拆成可复用的结构公式，再按四步把它换成自己的内容——学的是骨架，不是表层。

> 前提：只拆用户自己看到的公开笔记信息（肉眼记录或手工录入），不采集他人隐私、不爬取数据。把你看竞品时记下来的东西填进框架即可。

## 一、八维拆解框架

每拆一篇对标笔记，按这八维逐项记录。每维既记"它是什么样"，也记"为什么这样设计"，后者才是可迁移的东西。

| 维度 | 记录什么 | 为什么重要 |
|---|---|---|
| 封面 | 版式、主标字数、配色、主体物 | 决定点击率，是进池的入场券 |
| 标题 | 公式类型、关键词位置、钩子句式 | 决定搜索命中与被点开的意愿 |
| 选题 | 需求类型（痛点/好奇/利益/身份）、竞争度 | 决定内容有没有人关心 |
| 首图钩子 | 前三秒画面、前三行文字给了什么 | 决定用户划不划走、看不看完 |
| 结构 | 清单/教程/测评/避坑/故事，分几点 | 决定信息密度和阅读节奏 |
| 可存性 | 有无清单、表格、步骤、可照抄的干货 | 收藏是最高权重指标 |
| 互动设计 | 结尾是否留口子、如何引导评论 | 决定互动率能不能进下一层池 |
| 人设 | 主页三件套、关注理由是否清晰 | 决定流量能不能沉淀成粉丝 |

拆解时给每维打0-5分（见配套工具），总分40。重点看"最弱三维"——那是对标笔记都做得不够、你可以超越的地方；也要看"最强维"，那是它爆的核心原因，值得学。

## 二、从拆解到复用的四步

拆解不是目的，复用才是。四步缺一不可，跳过第三步就是照抄。

| 步骤 | 做什么 | 输出物 | 要点 |
|---|---|---|---|
| 1. 拆骨架 | 用八维框架记录对标笔记 | 一张拆解表+结构公式 | 用"分几点、什么顺序、每点讲什么"描述 |
| 2. 找重复 | 拆3-5篇同类爆款，找共同点 | 一份"套路清单" | 反复出现的结构才是真公式，别学个例 |
| 3. 换皮 | 骨架保留，表层全换 | 你的新选题大纲 | 措辞、经历、图片、案例全部换成自己的 |
| 4. 验证 | 发出去看数据 | 实测结果 | 看点击率收藏率是否达标，再迭代骨架 |

第3步是最容易翻车的地方。判断"换皮是否彻底"的四问：

- **措辞换了没**：不能出现和原文相同的整句（≥10字相同句即判定搬运风险）。
- **经历换了没**：故事必须是自己亲历的，不能把别人的经历换个名字。
- **图片换了没**：封面、配图全部自己拍或自己做，不能搬运原图。
- **案例换了没**：举例、数据、场景换成自己的素材。

## 三、三个拆解样例

下面是三种常见爆款类型的拆解示范。注意每个样例只给"结构公式"，具体措辞和经历都要换成你自己的。

### 样例A：清单型

| 维度 | 拆解记录 |
|---|---|
| 封面 | 纯色底+6个大字"通勤包只留5件"+5件物品平铺 |
| 标题 | 清单+排除式："通勤包我只留这5件，其他全退了" |
| 钩子 | 首图直接亮出5件清单，不铺垫 |
| 结构 | 5个物品×（价格/为什么留/一个缺点），逐条并列 |
| 可存性 | 清单型天然可存，用户会照着买 |
| 复用公式 | 场景+"只留N个"+逐条（是什么/为什么/缺点） |

### 样例B：避坑型

| 维度 | 拆解记录 |
|---|---|
| 封面 | 大字"别再买错了"+踩坑物品打红叉对比 |
| 标题 | 痛点+否定式："新手买xx，这4个坑我替你踩过了" |
| 钩子 | 前三行直接说"我花了多少钱买了教训" |
| 结构 | 先讲惨痛结果→4个坑逐个拆（现象/后果/正确做法） |
| 可存性 | "避坑清单"值得存，用户下单前会翻出来 |
| 复用公式 | 我先踩坑→N个坑×（现象/后果/正确做法）→正向总结 |

### 样例C：故事型

| 维度 | 拆解记录 |
|---|---|
| 封面 | 真人出镜+情绪化大字，营造代入感 |
| 标题 | 身份+反差："从月薪3千到存下10万，我做对了什么" |
| 钩子 | 开头抛结果和身份，制造"凭什么"的好奇 |
| 结构 | 低谷→转折→做了哪几件事→现在的结果→给同类人的建议 |
| 可存性 | 较弱，靠情绪和认同驱动互动，需补一句可执行的总结 |
| 复用公式 | 我的低谷→转折事件→N个具体动作→结果→给同类人的话 |

故事型的软肋是可存性低，复用时可以在结尾补一张"行动清单"图，把情绪型内容补成半工具型，收藏率会明显改善。

## 四、拆骨架，不抄表层

这是全篇最关键的一条：**保留结构公式，换掉全部措辞、经历、图片**。骨架是"分5点、每点讲价格+理由+缺点"这种抽象结构，谁用都不算抄；表层是具体的句子、你的故事、你的照片，照搬别人的就是搬运。

| 可以学（骨架） | 不能抄（表层） |
|---|---|
| 清单+排除的标题公式 | 原标题一字不改 |
| 先结果后过程的叙事顺序 | 原句照搬（≥10字相同句） |
| "现象/后果/做法"的三段结构 | 别人的亲身经历 |
| 红叉对比的封面版式思路 | 直接搬运原图 |
| 结尾开放式提问的互动设计 | 复制粘贴整段正文 |

整句照抄会限流，这是机制层面的事实，不是道德劝说。发之前用合规机检扫一遍整句重合（见配套工具），机检只能查句子雷同，图片和经历的原创要靠自己把关。

## 五、配套工具

竞品拆解和打分交给 `scripts/competitor.py`，把八维框架代码化，纯本地运行。

```bash
# 先看内置样例，熟悉八维打分与"最弱三维"输出
python3 competitor.py --demo

# 拆一篇：把肉眼记录的信息填进 JSON（每维填 score 0-5，可加 xxx_note 说明）
python3 competitor.py note.json

# 对标差距：mine.json 是你自己，rival.json 是对标，输出逐维分差
python3 competitor.py mine.json --vs rival.json

# 需要结构化结果时加 --json
python3 competitor.py note.json --json
```

- 八个维度键名：`cover/title_formula/topic/hook/structure/saveable/interaction/persona`，各填0-5分；每维可加同名 `_note` 字段写观察记录。
- 总分≥32判为"爆款骨架"、≥24"有潜力"、更低"骨架偏弱"；脚本会列出最弱三维。
- `--vs` 输出"我方−对标"的逐维分差，直接告诉你该补哪几维，比主观感觉准。
- 退出码0为完成，1为输入错误。分数是辅助判断，真正决定要不要学的是"这个结构能不能套进你的定位"。
