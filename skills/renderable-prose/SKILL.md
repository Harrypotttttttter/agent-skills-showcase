# 可渲染行文工坊

生成模型的文字理解有一个硬特点：**它只能拍到具体的东西，抽象的概念拍不到**。
「他很愤怒」拍不出愤怒，模型只会给一张平淡的脸；「下颌收紧，肩线抬高，右手握拳」能拍。
「电影感」是空词，「35mm 定焦、f/2.8、光比 3:1」能拍。

这个 skill 只解决一件事：**让提示词里的每一句文字都落得到像素上**。

## 边界：这个 skill 管什么，不管什么

| 层 | 内容 | 谁负责 |
|---|---|---|
| **行文层（本 skill）** | 句子怎么写才可拍、可感、可评分 | 本 skill |
| 排版层 | `[Shot N]`、时间窗、帧网格、素材编号、上传顺序 | minimax-h3-prompt 等排版类技能 |
| 剧情层 | 故事讲什么、人物动机、情节转折 | 作者与编剧，不在本 skill 范围 |

用户要求写分镜、切时间窗、规划参考图上传顺序 → 明确说明这属于排版层，移交对应技能。
用户只给一段文字、问「这样写行不行」「怎么写模型才拍得出来」「这段提示词有什么问题」→ 本 skill 全权处理。

## 三条铁律

1. **不可渲染的词，必须换掉，不许解释。** 抽象形容、空风格词、抽象隐喻、内心独白——模型拍不到就别写。「他很愤怒」不是「他愤怒」也不是「他看起来愤怒」，是「下颌收紧，肩线抬高」。
2. **改写优先于评论。** 用户要的是能用的句子，不是关于句子的评论。能自动改的一律给出改后文本和前后对照；不能自动改的，给出具体可替换的候选。
3. **语法安全高于改动幅度。** 原地替换会破坏句法时（例如把「空气里弥漫着电影感」里的「电影感」直接换成摄影参数），就把空词摘出正文、转成末尾的渲染约束行，而不是硬塞进去改坏句子。

## 工作流

### 一、先确认三件事（缺关键的就问，最多问 2 个）

1. **目标模型**：不同模型对同一句话的反应不同（负面字段、参考图语法、对白语速、颜色是否渲染成发光体）。用户没说就按 `generic` 保守档跑，并在结论里说明。
2. **这段文字的用途**：是正文描述、对白、旁白、还是约束句？不同用途的可渲染标准不同。
3. **是要审还是要改**：只审 → 出体检报告；要改 → 直接给改后全文。

### 二、跑体检

```bash
python scripts/prose_lint.py <文件> --dialect <方言>
python scripts/prose_lint.py <文件> --dialect <方言> --json
python scripts/prose_lint.py --list-dialects
```

输出三部分：**分级问题清单**（错误/警告/提示，每条带定位与改法）、**可渲染度评分**（0–100，五维分项）、**密度指标**（具象名词密度、感官密度、句长标准差、朗读时长）。

评分分项与含义：

| 分项 | 25 分满分意味着 |
|---|---|
| 具体度 | 具象名词密度达到 4 个/百字以上 |
| 感官层 | 听觉/触觉/嗅觉/动觉四层都有覆盖 |
| 无空词 | 没有弱风格词与抽象形容 |
| 无硬伤 | 没有 ERROR 级问题（画面内文字、负面字段等） |
| 节奏 | 句长有变化、无超长句 |

### 三、要改就自动改

```bash
python scripts/prose_rewrite.py <文件> --dialect <方言> --diff
python scripts/prose_rewrite.py <文件> --dialect <方言> --out 改后.txt
python scripts/prose_rewrite.py <文件> --dialect <方言> --json
```

改写器只动**能判定**的部分：空风格词、情绪直述、光色高危词、画面内具体文字、独立负面段、叠加副词，以及对白节奏压缩——按方言语速把台词换算成朗读秒数，超单次窗口时只删填充词/叠字（不动实词）；压不下来只报建议、不硬改。

**不动**：隐喻、剧情、情节——那些需要作者判断，体检报告里会指出位置，但由作者自己改。

`--json` 输出含 `dialogue_budget` 字段（各模型语速、单次窗口上限、台词字数、估算秒数、是否超窗、压缩段数、精简建议），可在报表里直接引用。

### 四、输出给用户

先给**改后可用文本**（不是问题清单），再给**变更清单**（before → after → 为什么），
最后给**评分变化**（改前多少、改后多少）。
如果有不自动改的部分（隐喻、剧情），单独列出来，说明为什么需要人来定。

## 写作时直接套用的五条

1. **情绪写成身体信号。** 不写「他很愤怒」，写「下颌收紧，肩线抬高，右手握拳，拇指反复摩擦指节」。
2. **光写成光源和反射，不写光色。** 不写「暖光」「蓝光」「金光闪闪」，写「油灯火焰轻微晃动」「金属表面接住灯光」。
3. **画面内的字不写内容。** 写「its content strictly matching <Picture N>」，具体文字交给参考图或后期。
4. **每段至少三层感官。** 视觉之外必须有听觉（脚步、嗡鸣、雨声）或触觉（冷、湿、粗粝），否则画面是平的。
5. **不揭示的内容，用人物反应代替。** 不拍箱里有什么，拍他看到之后僵住了。

## 回归自测

改动脚本后跑一遍，两个夹具的结果必须稳定：

```bash
python scripts/prose_lint.py scripts/fixtures/prose-bad.txt --dialect minimax-h3
python scripts/prose_lint.py scripts/fixtures/prose-good.txt --dialect minimax-h3
python scripts/prose_rewrite.py scripts/fixtures/prose-bad.txt --dialect minimax-h3
```
