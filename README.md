# Agent Skills 作品集

可直接安装使用的 AI Agent 技能集，覆盖房产决策、母婴、3D 资产、网文写作、文案质检、小红书运营与模型接入部署。
所有技能均已发布到 SkillHub，安装后由模型自动路由调用，无需用户点名。

## 为什么做这套技能

Agent 的能力边界由 SKILL.md 决定——一段写好的规则，能让模型在特定任务上从"泛泛而谈"
变成"按可执行的标准作业"。这套作品集把作者在两个高频场景里积累的方法论，
编译成了模型能直接加载、能跑脚本、能量化验收的技能。

设计上坚持三条：

- **能算的交给代码，需要判断的留给模型**——AI 味、标点、密度这类有确定判据的判定写成脚本；
  方言是不是作者风格这类需要语境的留给模型。
- **规则外置成数据**——阈值、词表、模型差异放 JSON，加一个场景只改配置不动代码。
- **正反夹具回归**——每个带脚本的技能都配反例与正例，改动后跑一遍，结果不稳就不发布。

## 调用示例

技能由模型根据自然语言自动匹配，**不需要说"用某某 skill"**。

### 示例 1 · 买房砍价

> 用户：这套挂 520 万，满二不唯一，业主 2021 年 480 万入手，中介说底价 500 万一分不让，我能砍到多少？

命中「买房砍价军师」→ 输出三个价格区间（挂牌价 / 合理成交区间 / 心理底价推算）、
真假底价信号判断、三轮出价话术与让步阶梯、止损离场线。

### 示例 2 · 网文质检

> 用户：把这章检查一下，我怕 AI 味太重过不了稿。

命中「网文写作专家」→ 跑 `qc_check.py`，输出分级问题清单（ERROR/WARN/INFO）、
五维机器评分、过稿判定（PASS / REVISE / REJECT）。需要修的跑 `qc_fix.py` 出 diff。

### 示例 3 · 孕产陪伴

> 用户：末次月经 8 月 12 号，今天 12 月 8 号，孕几周？这周该干嘛？

命中「孕产新生儿陪伴」→ 算出孕 16 周 + 6 天，给出本周必做、本周留意、下周预告，
症状类问题自动附就医指征。

## 安装

在 SkillHub 搜索技能名安装：

```bash
skillhub search 网文写作专家
skillhub install webnovel-writing-expert
```

或用对话直接说"帮我找 XX 技能的 skill"，Agent 会检索并安装。
